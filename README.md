# 🍰 Belle Sucrée

Bem-vindo ao repositório da **Belle Sucrée**, um site institucional desenvolvido para uma confeitaria fictícia, com o objetivo de apresentar seus produtos, sua história e facilitar a experiência dos clientes durante a navegação e realização de pedidos.

O projeto foi desenvolvido utilizando as principais tecnologias da web, aplicando conceitos de organização de páginas, responsividade, versionamento de código e boas práticas de desenvolvimento front-end.

---

# 📖 Sobre o Projeto

A **Belle Sucrée** é uma confeitaria especializada na produção de bolos, doces, cupcakes, tortas e bolos personalizados para diversas ocasiões.

O site foi desenvolvido para oferecer uma experiência agradável aos visitantes, permitindo conhecer a empresa, visualizar seus produtos, acompanhar receitas por meio de um blog e finalizar pedidos através de uma página de carrinho.

Além do site principal, foi criada uma **Landing Page** com o objetivo de atrair novos clientes e divulgar os principais produtos e serviços da confeitaria.

# 🛠️ Tecnologias Utilizadas

## Wireframe

Utilizado para a criação dos protótipos e planejamento da interface antes do desenvolvimento do projeto.

## HTML5

Responsável pela estruturação das páginas e organização do conteúdo.

## CSS3

Utilizado para estilização, layout, responsividade e identidade visual da aplicação.

## Bootstrap

Framework CSS utilizado para agilizar o desenvolvimento da interface por meio de componentes e estilos pré-definidos.

Também foram utilizados os scripts JavaScript disponibilizados pelo Bootstrap para adicionar funcionalidades aos componentes da interface.

## Git

Sistema de controle de versão utilizado durante todo o desenvolvimento do projeto.

## GitHub

Plataforma utilizada para hospedagem do repositório e gerenciamento das versões do projeto.

1. Clone este repositório:


2. Acesse a pasta do projeto.

3. Abra o arquivo `index.html` em seu navegador.

Ou utilize uma extensão como **Live Server** no Visual Studio Code para uma melhor experiência durante o desenvolvimento.
